──────　色変え方法　──────




１．テクスチャデータ［neko テクスチャ］から変更したい部位フォルダを選択し最下層にあるtextureファイルをコピーします。
２．そのままモデルデータ［neko］内の［neko.4096］にペーストし、上書きを行います。
３．Vtubestudioや使用ソフト内でモデルを起動しモデルのリロードを行ってください。（Vtubestudioの場合初期キーF1を押すとテクスチャ更新ができます）
４.色が変わっていたら成功です。

※フォルダではなくtextureファイルをコピーする様にしてください。

────── How to change colors ──────




1) Select the folder of the part you want to change from the texture data [neko texture] and copy the texture file at the bottom of the folder. 2) Go into the model data [neko.40] and copy the texture file.
Paste the file into [neko.4096] in the [neko] model data and overwrite it. 3.
3. Start the model in Vtubestudio or the software used and reload the model. (In Vtubestudio, you can update the texture by pressing the initial F1 key.)
4. If the colors have changed, you have succeeded.

Make sure to copy the texture file, not the folder.



────── Differential changes such as hair length, highlights, etc. (Vtubestudio only) ──────




1. Start Vtubestudio. 2.
2. From Settings⚙, select the rightmost of the four icons in the upper left corner of the screen.
3. Select [Expression File Editor] on the right side of the screen, then select [Create New Expression File].
4. Adjust the parameters at the top of the screen: [Hair Length Side], [Hair Length Front], [Hair Length Back], [No Ear Tail], [No Head Ribbon], [White Pupils], [No Choppy Hair], [No Highlights], [No Bell], [No Choker], [No Hair Pin], and save the expression file with a name that is easy to recognize. Save the file with a clear file name.
5. Scroll down from the screen  2⃣ and press the plus + button.
6. Set the Action Type to Switch Expression (exp3).
　 Set the expression to the expression file you just saved.
　 Set the key combination as you wish.
7. Press the key set in the key combination, and if the appearance changes as described in step (4), you have succeeded.



In some cases, Live2DViewer can be used without Vtubestudio.


────── Changing the text on the T-shirt ──────


1. Load the texture file of the garment you want to change into an image processing software. (If you can save the file as a transparent png file)
2. Insert your favorite text, illustration, photo, etc. into the frame of the texture and save the file over the original data so that the canvas size, name, and texture position remain the same.
Check the T-shirt in Vtubestudio and if the T-shirt has been changed, you have succeeded. If the T-shirt has changed, you have succeeded.
